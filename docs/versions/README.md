# Versions

0.x versions are internal steps; 1.0 is the first public release on the App Store and Play Store.

One folder per public release (`1/`, `2/`, …). Inside it, one folder per internal step
(`1/0.1/`, `1/0.2/`, …) holding `requirements.md` — high-level functional requirements
agreed before any design or code, tracked by a GitHub Task issue.

| Version | Theme | Requirements | Status |
|---------|-------|--------------|--------|
| 0.1 | Single-player: capture accuracy, exploration, passport | [1/0.1/requirements.md](1/0.1/requirements.md) | Draft — [#198](https://github.com/WarPro-Org/my_loop/issues/198) |

Where a version's requirements disagree with `docs/product/spec.md`, the version doc wins.
