# Versions

One folder per major version (`0/`, `1/`, …); each release inside it gets its own
`<version>-requirements.md` with high-level functional requirements agreed before any design or code, and is
tracked by a GitHub Task issue.

| Version | Theme | Requirements | Status |
|---------|-------|--------------|--------|
| 0.1 | Single-player capture accuracy | [0/0.1-requirements.md](0/0.1-requirements.md) | Draft — [#198](https://github.com/WarPro-Org/my_loop/issues/198) |

Where a version's requirements disagree with `docs/product/spec.md`, the version doc wins.
