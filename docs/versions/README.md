# Versions

One folder per version. Each version starts with high-level functional
requirements (`requirements.md`) agreed before any design or code, and is
tracked by a GitHub Task issue.

| Version | Theme | Requirements | Status |
|---------|-------|--------------|--------|
| 0.1 | Single-player capture accuracy | [v0.1/requirements.md](v0.1/requirements.md) | Draft — [#198](https://github.com/WarPro-Org/my_loop/issues/198) |

Where a version's requirements disagree with `docs/product/spec.md`, the version doc wins.
